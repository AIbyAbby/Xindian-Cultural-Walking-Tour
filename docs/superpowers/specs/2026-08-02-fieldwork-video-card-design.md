# 「溪與城的踏查足跡」影片卡片設計

## 目標

在首頁「田調記憶」區塊的所有既有卡片之後，新增一張可直接播放 YouTube 影片的卡片，延續網站現有的視覺語言與閱讀節奏。

## 卡片內容與順序

1. 主標題：溪與城的踏查足跡
2. 副標：空拍影像紀實／陳翠碧
3. 16:9 YouTube 播放器
4. 介紹文字：使用委託方提供的完整段落，不改寫內容

## 互動與版面

- 播放器直接顯示於卡片內，訪客不必離開網站即可播放。
- 使用 YouTube 隱私加強模式的嵌入網址，並啟用延遲載入。
- 播放器維持 16:9 比例，在桌面與手機寬度下自動縮放。
- 卡片沿用既有米白背景、圓角、邊框與陰影；影片卡片本身不作為整張超連結，以免與播放器操作衝突。
- 提供清楚的影片標題與允許全螢幕播放的設定。

## 驗證

- 確認卡片位於「田調記憶」最下方。
- 確認標題置於卡片內容最上方，副標、播放器與介紹文字順序正確。
- 確認 YouTube 影片代碼為 `td_MB7xD1as`。
- 確認 HTML 結構、響應式比例與現有卡片樣式均正常。
